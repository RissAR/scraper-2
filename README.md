# 🏢 RieltorBot — Моніторинг нерухомості в Telegram (MVP: OLX.ua Дніпро)

Асинхронний Telegram-бот для моніторингу появи нових оголошень про оренду 1-кімнатних квартир у м. Дніпро в реальному часі.

---

## 🚀 Ключові можливості

1. **Фільтрація оголошень:**
   - **Місто:** Дніпро (ID міста в OLX: `121`).
   - **Тип:** 1-кімнатна квартира (довгострокова оренда, категорія OLX `1760`).
   - **Ціновий діапазон:** налаштовується в `.env` (`MIN_PRICE`, `MAX_PRICE`).
   - **Виключення районів:** можливість виключити непотрібні райони (`EXCLUDED_DISTRICTS`).
   - **Захист від дублікатів та піднятих у ТОП:** старі оголошення, підняті платною рекламою в ТОП, автоматично фільтруються за датою публікації `created_time` та історією бази даних.

2. **Інтерактивний Inline-інтерфейс у Telegram:**
   - **Запуск / Пауза моніторингу:** керування фоновим парсером інлайн-кнопками (`[▶️ Запустити]` / `[⏸ Зупинити]`).
   - **Управління проксі:** меню додавання, видалення та діагностики статусу (активний / пінг / помилка).
   - **Перегляд об'єктів у базі:** компактний перегляд карток з пагінацією без засмічення стрічки чату.
   - **Експорт в Excel:** швидке завантаження таблиці `.xlsx` з повними даними про всі оголошення.
   - **Розумні сповіщення:** сповіщення про завершення парсингу та додавання об'єктів з інлайн-кнопкою `[Показати об'єкти]`.

3. **Стійкість та архітектура:**
   - Стек: **Python 3.12**, **aiogram 3**, **httpx (HTTP/2, SOCKS5)**, **aiosqlite**, **openpyxl**, **Pydantic v2**.
   - Підтримка пулу HTTP / SOCKS5 **проксі** у базі даних SQLite з автоматичною ротацією.
   - Робота в фоновому циклі з інтервалом 2–4 хвилини (`POLL_INTERVAL_SECONDS`).
   - Легкий запуск та ізоляція через **Docker** та **docker-compose**.

## ⚙️ Налаштування (.env)

Створіть файл `.env` на основі `.env.example`:

```bash
cp .env.example .env
```

| Параметр | Опис | За замовчуванням |
|---|---|---|
| `BOT_TOKEN` | API токен Telegram-бота | `YOUR_BOT_TOKEN_HERE` |
| `TELEGRAM_CHAT_ID` | ID чату/каналу (можна декілька через кому) | `(порожньо, надсилає всім за /start)` |
| `POLL_INTERVAL_SECONDS` | Інтервал перевірки в секундах | `180` (3 хвилини) |
| `MIN_PRICE` | Мінімальна ціна (грн) | `3000` |
| `MAX_PRICE` | Максимальна ціна (грн) | `25000` |
| `EXCLUDED_DISTRICTS` | Райони для виключення через кому | `(порожньо)` |
| `PROXY_URL` | Адреса проксі (опціонально) | `(порожньо)` |
| `MAX_AD_AGE_HOURS` | Максимальний вік оголошення для відсіювання старих ТОП | `48` |
| `INIT_MARK_AS_SEEN` | Не спамити старими оголошеннями при першому запуску | `true` |

## 🐳 Запуск через Docker (Рекомендовано)

Запуск на сервері в один клік:

```bash
docker compose up -d --build
```

Перегляд логів:
```bash
docker compose logs -f
```

Зупинка:
```bash
docker compose down
```

---

## 💻 Локальний запуск (без Docker)

1. Створіть та активуйте віртуальне оточення:
```bash
python3 -m venv .venv
source .venv/bin/activate
```

2. Встановіть залежності:
```bash
pip install -r requirements.txt
```

3. Запустіть тест скрапера:
```bash
python test_olx.py
```

4. Запустіть бота:
```bash
python bot.py
```

## 🤖 Команди бота в Telegram

- `/start` — Запустити бота, зареєструвати чат для отримання сповіщень та переглянути поточні фільтри.
- `/status` — Переглянути статистику (кількість збережених оголошень, надісланих сповіщень, активних підписників).
- `/check` — Примусово запустити пошук нових оголошень прямо зараз.
- `/stop` — Зупинити отримання сповіщень.

# 🏢 RieltorBot — Автономна система моніторингу нерухомості від власників (OLX.ua & DIM.RIA)

Потужний асинхронний Telegram-бот для моніторингу нових оголошень про довгострокову оренду 1-кімнатних квартир у м. Дніпро в режимі реального часу (інтервал 2–4 хвилини) **виключно від прямих власників** з відсіканням посередників та ріелторів.

---

## 🌟 Ключові можливості та архітектура

### 1. Подвійний скрапінг у реальному часі (Dual-Source Engine)
- **OLX.ua API & On-Demand Playwright:**
  - Швидке отримання свіжих пропозицій через офіційний JSON API OLX з параметром `owner_type=private`.
  - Збагачення даними: поверх, поверховість, загальна площа, дата публікації, фотографії високої якості.
  - On-Demand headless Chromium (Playwright) для розкриття номерів телефонів власників, обходу Cloudflare/Friction SDK та взаємодії з елементами інтерфейсу.
- **DIM.RIA (dom.ria.com) Scraper:**
  - Попередній пошук кандидатів через `searchEngine/v2` з обов'язковим фільтром «Від власника» (`1437_1436`).
  - Попередня дедуплікація в пам'яті та базі даних SQLite до запуску браузера для економії ресурсів.
  - On-Demand вилучення повних характеристик, описів та перехоплення контактних даних через Playwright.

### 2. Багаторівневий анти-ріелтор фільтр (Anti-Realtor Shield)
- **Рівень 1 (Тип профілю):** Відсікання акаунтів типу `business` / `agency`.
- **Рівень 2 (Семантичний аналіз):** Жорсткий список стоп-слів («комісія», «агентство», «АН», «рієлтор», «послуги ріелтора», «колегам не турбувати», «співпрацюю» тощо) з урахуванням контексту (наприклад, «без комісії» або «без ріелторів» дозволяються).
- **Рівень 3 (Ліміт активних оголошень):** Перевірка кількості активних оголошень автора (`author_ads_count <= 2`). Якщо в акаунта більше 2 оголошень — це прихований ріелтор/агентство, оголошення відхиляється.

### 3. Дворівнева рольова модель (RBAC)
- **Кабінет Адміністратора:**
  - Роздільне керування парсерами: увімкнення/зупинка OLX.ua та DIM.RIA окремо або одночасно.
  - Швидке тестове опитування в 1 клік (`🔍 Тест OLX (1 коло)`, `🔍 Тест DIM.RIA (1 коло)`).
  - Управління користувачами: перегляд зареєстрованих ріелторів, схвалення/відхилення заявок на доступ, блокування, призначення адмінів.
  - Пул проксі: додавання, видалення, автоматична перевірка здоров'я та пінгу.
  - Гаряче оновлення Cookies: встановлення/очищення авторизованих сесійних кукі OLX без перезапуску сервісу.
  - Експорт в Excel: вивантаження повної бази об'єктів у форматі `.xlsx`.
  - Системний статус: детальна статистика БД, стан фонового сканера та запобіжників Circuit Breaker.
- **Кабінет Ріелтора:**
  - Компактний клієнтський інтерфейс: перегляд актуальних перевірених квартир у базі з пагінацією.
  - Персональні сповіщення про надходження нових об'єктів від власників у режимі реального часу.
  - Інформація про власний статус та технічну підтримку.
- **Неавторизовані користувачі:**
  - Повне блокування доступу до функціоналу з можливістю надіслати заявку адміністраторам на отримання прав.

### 4. Відмовостійкість, Resilience та Захист пам'яті
- **Graceful Degradation (Плавна деградація):** Якщо номер телефону не вдалося розкрити автоматично (таймаут або блокування кнопки), об'єкт від власника **не втрачається**, а надсилається з позначкою: `📞 Телефон: Не розкрито автоматично (перегляньте за посиланням нижче)`.
- **Circuit Breaker & Cooldown:** При отриманні статусів `429 Too Many Requests`, `403 Forbidden` або помилках мережі скрапер автоматично ротує проксі. При 3 поспіль помилках парсер переходить у режим «Cooldown» (пауза 15 хв) для захисту IP від бана.
- **Auto-Alerts в Telegram:** Автоматичне надсилання повідомлень адміністраторам при 3 збоях парсера та сповіщення про відновлення штатної роботи.
- **Watchdog & Memory Protection:** Кожен запуск Playwright обмежений жорстким таймаутом `asyncio.wait_for(..., timeout=25.0)`. Блоки `finally` гарантовано закривають `page`, `context` та `browser`, унеможливлюючи витоки RAM та зомбі-процеси Chromium.
- **Hot-Reload Cookies:** Можливість передати нові cookies через команду `/set_cookies` або адмін-меню для збереження в SQLite та миттєвого підхоплення парсером.

## 📁 Структура проекту

```
RieltorBot/
├── bot.py               # Точка входу: aiogram бот, диспетчер меню, RBAC, фоновий сканер та алерти
├── keyboards.py         # Інлайн-клавіатури для Адміністратора, Ріелтора, пагінації та кукі
├── olx_scraper.py       # Асинхронний скрапер OLX.ua (API + On-Demand Playwright)
├── dimria_scraper.py    # Асинхронний скрапер DIM.RIA (searchEngine/v2 + Playwright)
├── database.py          # Асинхронний менеджер SQLite (aiosqlite): оголошення, користувачі, стан, проксі
├── proxy_checker.py     # Модуль діагностики працездатності та швидкості відгуку проксі
├── exporter.py          # Генерація звітів бази об'єктів у формат Excel (.xlsx)
├── models.py            # Pydantic моделі даних (ListingItem)
├── config.py            # Типізована конфігурація Pydantic Settings з підтримкою .env
├── test_olx.py          # Автономний тест скрапера OLX, фільтрації та бази даних
├── test_dimria.py       # Автономний тест скрапера DIM.RIA
├── requirements.txt     # Залежності Python
├── Dockerfile           # Багатошаровий Docker-образ (з Playwright Chromium)
├── docker-compose.yml   # Конфігурація для швидкого деплою
├── .env.example         # Шаблон змінних оточення
└── data/                # Збереження SQLite бази даних (rieltor_bot.db) та логів
```

## ⚙️ Налаштування (.env)

Створіть файл `.env` на основі шаблону:

```bash
cp .env.example .env
```

| Параметр | Опис | Приклад значення |
|---|---|---|
| `BOT_TOKEN` | API токен Telegram-бота від @BotFather | `YOUR_BOT_TOKEN_HERE` |
| `ADMIN_IDS` | Telegram ID адміністраторів через кому | `123456789` |
| `TELEGRAM_CHAT_ID` | Опціональний ID каналу/чату для дублювання стрічки | `(порожньо для розсилки користувачам)` |
| `POLL_INTERVAL_SECONDS` | Інтервал сканування в секундах (2–4 хв) | `180` |
| `CITY_NAME` | Назва міста для пошуку | `Дніпро` |
| `CITY_ID` | ID міста в системі OLX (Дніпро = 121) | `121` |
| `CATEGORY_ID` | Категорія OLX (1760 = 1-кімн. оренда) | `1760` |
| `MIN_PRICE` | Мінімальна ціна в грн (опціонально) | `3000` |
| `MAX_PRICE` | Максимальна ціна в грн (опціонально) | `25000` |
| `EXCLUDED_DISTRICTS` | Райони для виключення через кому | `(порожньо або список районів)` |
| `ONLY_OWNERS` | Жорстка фільтрація виключно власників | `true` |
| `MAX_OWNER_ACTIVE_ADS` | Максимум активних оголошень у автора | `2` |
| `MAX_AD_AGE_HOURS` | Відсіювання старих піднятих у ТОП оголошень | `48` |
| `INIT_MARK_AS_SEEN` | Не спамити старими оголошеннями при старті | `true` |
| `DIMRIA_ENABLED` | Увімкнення моніторингу DIM.RIA | `true` |
| `DIMRIA_STATE_ID` | ID області в DIM.RIA (Дніпропетровська = 11) | `11` |
| `DIMRIA_CITY_ID` | ID міста в DIM.RIA (Дніпро = 11) | `11` |
| `OLX_COOKIES` | Сесійні cookies OLX для авторизованого контексту | `name=val; name2=val2` |
| `PROXY_URL` | Базовий проксі за замовчуванням (опціонально) | `http://user:pass@ip:port` |
| `DB_PATH` | Шлях до файлу бази SQLite | `data/rieltor_bot.db` |

## 🚀 Швидкий запуск

### Варіант 1. Запуск через Docker Compose (Рекомендовано для продакшну)

```bash
# 1. Клонувати репозиторій
git clone https://github.com/RissAR/scraper-2.git
cd scraper-2

# 2. Налаштувати конфігурацію
cp .env.example .env
nano .env

# 3. Запустити сервіс у фоні
docker compose up -d --build

# 4. Перегляд логів у реальному часі
docker compose logs -f
```

### Варіант 2. Локальний запуск на сервері / розробці (Ubuntu / Linux)

```bash
# 1. Створити та активувати віртуальне середовище
python3 -m venv .venv
source .venv/bin/activate

# 2. Встановити залежності Python
pip install -r requirements.txt

# 3. Встановити Chromium для Playwright та системні бібліотеки
playwright install chromium
playwright install-deps chromium

# 4. Перевірити роботу парсерів
python test_olx.py
python test_dimria.py

# 5. Запустити бота
python bot.py
```

## 🛡️ Безпека та обслуговування

1. **Ротація проксі:** Додайте робочі HTTP/SOCKS5 проксі через меню бота `🌐 Меню проксі` для автоматичного балансування навантаження та захисту від обмежень IP.
2. **Сесійні Cookies:** При зміні політик OLX отримайте свіжі cookies через Chrome DevTools і збережіть їх командою `/set_cookies` або кнопкою `🍪 OLX Cookies`.
3. **Бекап бази даних:** Усі збережені оголошення, користувачі та налаштування зберігаються у файлі `data/rieltor_bot.db`. Монтування директорії `data/` зберігає всі дані при перезапуску або перезбірці Docker-контейнера.

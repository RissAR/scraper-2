# ТЕХНІЧНЕ ЗАВДАННЯ: Скрапер DIM.RIA (DOM.RIA) для оренди квартир від власників у Дніпрі

## 1. Контекст та мета
* **Мета:** Інтегрувати скрапер порталу `DIM.RIA` (`dom.ria.com`) в єдиний потік бота поруч із `OLX.ua`.
* **Завдання:** Моніторинг нових 1-кімнатних квартир у м. Дніпро, жорстке відсіювання 100% ріелторів, витягування характеристик, фото, повного опису та прямого номера телефону власника.

---

## 2. Результати аналізу API та Архітектура (Reverse Engineering Findings)

1. **Етап 1: Пошук нових об'єктів (Швидкий HTTP-запит)**
   * **URL:** `GET https://dom.ria.com/node/searchEngine/v2/`
   * **Ключові параметри фільтрації:**
     - `category=1` — нерухомість (квартири).
     - `realty_type=2` — тип нерухомості (квартира).
     - `operation=3` — довгострокова оренда.
     - `state_id=11` — Дніпропетровська область.
     - `city_ids=11` — м. Дніпро.
     - `ch=209_1,1437_1436` — **КРИТИЧНО:**
       * `209_1` — 1 кімната.
       * `1437_1436` — тип пропозиції **«ВІД ВЛАСНИКА»** (`1437` = тип пропозиції, `1436` = від власника). Відсіює більшість посередників на рівні бекенду RIA!
     - `wo_dupl=1` — без дублікатів.
     - `limit=20` (або до 40).
     - `sort=inspected_sort` (або сортування за датою надходження).
   * **Формат відповіді:**
     `{"count": 929, "items": [35010178, 35001396, ...]}` — масив числових ID.

2. **Етап 2: Дедуплікація (SQLite Database)**
   * Складений ідентифікатор: `dimria:{item_id}`.
   * Якщо ID уже є в `seen_listings` — пропускаємо.

3. **Етап 3: Отримання опису, фото та номера телефону (On-Demand Playwright)**
   * Оскільки сторінки DIM.RIA використовують серверний рендеринг (SSR), захист Cloudflare та динамічний хеш для виклику `getOwnerAndAgencyData`:
   * **URL сторінки:** `https://dom.ria.com/uk/realty_pereglyad-{item_id}.html` (або прямий URL перегляду).
   * **Оптимізація ресурсів:** через `page.route` блокувати шрифти, медіа-трекери та важкі анімації.
   * **Вилучення даних зі сторінки:**
     - **Опис:** елемент `#descriptionBlock` (`page.locator("#descriptionBlock").inner_text()`).
     - **Фото:** галерея картинок (`img` з доменом `cdn.riastatic.com`) або `meta[property='og:image']`.
     - **Параметри:** поверх, поверховість, площа, ціна та район з блоку характеристик.
   * **Анти-ріелтор валідація 2-го рівня:**
     - Перевірка опису та блоку характеристик на стоп-слова: "комісія", "100%", "послуги", "АН", "рієлтор".
     - Якщо в характеристиках знайдено "Комісія за послуги" — відхилити як ріелтора!
   * **Вилучення номера телефону:**
     - Натиснути помаранчеву кнопку контактів (наприклад, кнопка з текстом `(067) XXX XX XX` або селектором блоку контактів продавця).
     - Перехопити відповідь `GET /v1/api/realty/getOwnerAndAgencyData/` або прочитати оновлений текст кнопки з відкритим номером.
     - Валідація: перевірити поле `"gradation"` у відповіді API — якщо `"title"` містить `"рієлтор"`, відхилити!

## 3. Вимоги до реалізації (Implementation Scope)

### Крок 1. Модуль скрапера DIM.RIA (`dimria_scraper.py`)
* Реалізувати клас `DimRiaScraper` з методами:
  - `fetch_new_listing_ids(client: httpx.AsyncClient) -> list[int]`: швидкий запит до `searchEngine/v2/` з фільтром `1437_1436` (тільки від власника) та 1-кімнатні Дніпро.
  - `fetch_listing_details_playwright(item_id: int, browser_context) -> Optional[ListingItem]`: вилучення опису з `#descriptionBlock`, фото, параметрів, клік по кнопці номера та зчитування відкритого телефону.
  - Застосування уніфікованого фільтра стоп-слів ріелторів.

### Крок 2. Інтеграція в `config.py`
* Додати перемикач `DIMRIA_ENABLED: bool = True` (із можливістю відключення в `.env`).
* Додати базові константи пошуку DIM.RIA: `DIMRIA_STATE_ID = 11` (Дніпропетровська обл.), `DIMRIA_CITY_ID = 11` (Дніпро).

### Крок 3. Інтеграція в цикл моніторингу `bot.py`
* У фоновому воркері бота додати виклик `dimria_scraper.fetch_new_listings()`.
* Усі знайдені об'єкти від власників зберігаються в `database.py` під єдиною схемою `source = "DIM.RIA"`.
* Відправка повідомлень у Telegram у єдиному стандартному форматі з клікабельним номером власника.

## 4. Критерії приймання та перевірка (Verification)
1. Синтаксична перевірка: `python3 -m py_compile dimria_scraper.py bot.py config.py`.
2. Тестовий скрипт (наприклад, запуск тестового виклику на свіжому ID з `searchEngine/v2`):
   - Отримання свіжих ID від власників з Дніпра.
   - Успішне вилучення опису, фото та номера телефону без помилок.
   - Відсіювання об'єктів з позначкою комісії / ріелтора.
